How it works

  1. Safety screen Emergencies get fixed guidance (112 / 108) and skip the AI.
  2. CAG – semantic cache A validated earlier answer is reused only if the question has the same meaning, intent and clinical context (age group, pregnancy, type numbers).
  3. RAG – retrieval Otherwise the top-5 passages are found among 27k NIH passages (MedQuAD) using MiniLM embeddings.
  4. Evidence gate If nothing relevant is found, the system says so instead of guessing.
  5. Lightweight LLM writes a short answer that cites the passages.
  6. Validation Every sentence is checked against its cited passage before the answer is shown or cached.
